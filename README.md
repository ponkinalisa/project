## 📌 О проекте

Веб-приложение для редактирования изображений прямо в браузере. Позволяет загружать фото, применять различные эффекты, кадрировать изображения и сохранять результаты в личную галерею.

**Что умеет программа:**
- 📤 Загружать изображения
- 🎨 Применять эффекты (негатив, чёрно-белый, и др.)
- ✂️ Кадрировать изображения (обрезать)
- 💾 Сохранять отредактированные изображения
- 🖼 Просматривать галерею всех измененных фото

---

## 🎯 Актуальность

Редактирование изображений — востребованная задача. Однако многие пользователи не хотят устанавливать тяжёлые программы вроде Photoshop или искать онлайн-сервисы с ограничениями.

Приложение решает эти проблемы:
- не требует установки (работает в браузере)
- все функции собраны в одном месте
- фото хранятся в личной галерее
- быстрая обработка на сервере
